# Model-only slate archive

The September 29, 2026 tracker in this folder was generated on September 27 at 7:21 PM CT. It contains 297 player rows and the move kit tags, but no posted market lines or odds. It is kept as an original model-only record.

The daily grader reads priced pregame snapshots from `output/slates/tracker_YYYY-MM-DD.csv`. This archived file is intentionally outside that path so missing prices cannot be mistaken for settled bets. A September 29 priced tracker export, if found, can be added as the canonical snapshot and graded against final box scores.
